# Release Checklist

## Required before release

- `product` gate passed
- `engineering` gate passed
- `qa` gate passed
- `security` gate passed
- release notes captured
- `pnpm typecheck` passed
- `pnpm build` passed
- `pnpm test` passed

## Release evidence

- task ID
- worker ID
- gate evidence
- build/test command output
- rollout notes
