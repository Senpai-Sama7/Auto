# Design Review

Adapted from gstack's design checklist and reduced to a neutral frontend review asset.

## Anti-patterns

- Centered-everything layouts with weak hierarchy
- Generic purple-gradient hero patterns
- Uniform oversized border radii on every surface
- Missing hover and focus states
- Body text smaller than 16px
- Fixed-width layouts without mobile handling

## Output contract

- `AUTO-FIXED` for mechanical accessibility or CSS hygiene fixes
- `NEEDS INPUT` for judgment calls
- `POSSIBLE` only when a visual check is still required
